# /daily-schedule — 朝の工程表生成

合同会社MARUDEの1日の工程表を自動生成するスキル。毎朝「おはよう」と入力するだけで発動する。

## 実行手順

1. **Google Calendarから今日の予定を取得**
   - 接続済みカレンダーすべて（個人・会社・クライアント共有カレンダー等）
   - 取得できない場合はスキップし、ユーザーに確認する

2. **GitHub Issueから進行中・未着手タスクを取得**
   - リポジトリ: marudellc-commits/project1
   - フィルタ: `is:open` のIssue
   - 期限ラベルがあれば優先考慮

3. **DAILY.mdを読み込み**
   - 昨日の「未完了タスク（翌日へ）」セクションを確認
   - 繰り越しタスクがあれば今日のリストに追加

4. **03_projects/ を確認**
   - 各案件フォルダの状況ファイル（status.md等）を参照
   - 期限が近い案件（3日以内）をピックアップ

5. **タスクを分類**
   - 緊急×重要（今日中に必ず）
   - 重要だが緊急でない（計画的に取り組む）
   - 認知負荷が低い（隙間時間に処理）
   - デザイン作業（集中ブロックが必要）

6. **15分刻みの工程表を生成**
   - 9:00〜18:00を基本とする（ユーザーが変更可能）
   - 集中が必要なデザイン作業は午前中に配置
   - ミーティング・連絡対応は午後に配置
   - 昼休み（12:00〜13:00）は確保する

7. **DAILY.mdを更新**
   - 今日の日付で工程表を書き込む
   - 前日の記録はそのまま残す

## 出力フォーマット

```
## {日付} の工程表

### 🎯 今日の優先タスク（TOP3）
1. 
2. 
3. 

### ⏰ 工程表
| 時間 | タスク | カテゴリ |
|------|--------|---------|
| 9:00 |  |  |
...

### 📋 本日のカレンダー予定
-

### 🔄 繰り越しタスク
-
```

## 注意事項
- Google Calendar未接続時は「カレンダー未接続」と表示し、手動入力を促す
- GitHub未接続時はDAILY.mdの記録のみで工程表を生成
- 工程表はあくまで提案。ユーザーの確認後に確定とする
