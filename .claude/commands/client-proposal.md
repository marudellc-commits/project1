# /client-proposal — クライアント提案書自動生成

クライアント提案チームを起動し、要件整理から提案書下書きまでを自動生成するスキル。

## チーム構成

```
[要件整理エージェント] → [市場・競合リサーチエージェント]
                                         ↓
                        [デザイン提案エージェント]
                                         ↓
                        [提案書ライターエージェント]
                                         ↓
                        [提案書レビューエージェント]
```

## 実行手順

1. **起動トリガー**
   - 「提案書作って」「〇〇社の提案を作りたい」で発動

2. **ユーザーへの初期確認**（情報が不足している場合のみ）
   - クライアント名・業種
   - 主な要望・課題
   - 予算感・期限
   - 参考にしたいサイト（あれば）

3. **チームを順番に実行**

   **Step 1**: 要件整理エージェントを起動
   → 要件定義書を生成

   **Step 2**: 市場・競合リサーチエージェントを起動
   → リサーチ結果を生成

   **Step 3**: デザイン提案エージェントを起動
   → デザインコンセプト案を生成（2〜3パターン）

   **Step 4**: 提案書ライターエージェントを起動
   → 提案書下書きを `output/articles/{日付}_{クライアント名}_提案書.md` に保存

   **Step 5**: 提案書レビューエージェントを起動
   → レビュー結果を提示

4. **ユーザーへの最終報告**
   - 生成された提案書のパスを案内
   - レビューでBまたはC評価の場合は修正ポイントを提示
   - 「修正して」と言われたらライターエージェントに差し戻す

## 使用例

```
「〇〇整体院さんから、ホームページ作りたいって問い合わせが来た。
30代〜50代の女性がターゲット、予算は30万くらいって言ってた。
提案書作って」
```

## 出力物

- `output/articles/{日付}_{クライアント名}_提案書.md` — 提案書下書き
- `03_projects/{クライアント名}/requirements.md` — 要件定義書（Issue登録にも活用）

## 注意事項
- 料金は目安のみ記載。正式見積もりは別途 `/update-finance` スキルで作成
- 提案書は必ずユーザーが最終確認してから送付する
- クライアント情報は `00_context/memories/clients.md` にも保存する
