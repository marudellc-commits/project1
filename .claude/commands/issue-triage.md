# /issue-triage — タスク登録・GitHub Issue作成

ユーザーのテキスト入力から、合同会社MARUDEの業務に合わせたGitHub Issueを自動作成するスキル。

## 実行手順

1. **入力テキストを解析**
   - タスクの内容・背景・目的を把握
   - 関連するクライアント名・案件名があれば抽出
   - 期限・納期の記載があれば抽出

2. **タスクの分類・ラベル付け**

   **タイプ**:
   - `type:制作` — Webサイト・グラフィック・動画の制作作業
   - `type:提案` — 見積もり・企画・提案書の作成
   - `type:運用` — 保守・更新・SEO対応
   - `type:経理` — 請求・入金確認・経費処理
   - `type:マーケ` — コンテンツ・SNS・ブログ投稿
   - `type:internal` — 社内業務・ツール整備

   **優先度**:
   - `priority:high` — 今日〜3日以内に対応必要
   - `priority:medium` — 今週中
   - `priority:low` — 来週以降でOK

   **ステータス**:
   - `status:未着手`
   - `status:進行中`
   - `status:レビュー待ち`

3. **既存Issueとの重複チェック**
   - タイトルが似たIssueがあれば提示してユーザーに確認
   - 重複の場合はコメント追加を提案

4. **Issue本文を生成**
   ```
   ## 概要
   （タスクの内容）

   ## 詳細
   （背景・要件・参考情報）

   ## 完了条件
   - [ ] 

   ## 関連情報
   - クライアント: 
   - 期限: 
   - 参照フォルダ: 03_projects/[案件名]/
   ```

5. **GitHub Issueを作成**
   - リポジトリ: marudellc-commits/project1
   - ラベルを付与
   - 作成結果（Issue番号・URL）をユーザーに報告

## 使用例

```
「〇〇社のランディングページのデザイン案を今週中に3パターン出してほしい」
→ type:制作, priority:high でIssue作成
```

```
「先月の請求書をまとめて送らないといけない」
→ type:経理, priority:high でIssue作成
```

## 注意事項
- クライアント名を含むIssueは必要に応じて非公開（private）リポジトリで管理
- 機密性の高い案件はIssue本文に詳細を入れず、03_projects/ のフォルダを参照する形にする
