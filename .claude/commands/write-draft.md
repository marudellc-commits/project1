# /write-draft — コンテンツ下書き生成

テーマを受け取り、合同会社MARUDEのブランドに合ったコンテンツの下書きを生成するスキル。

## 対応コンテンツタイプ

- ブログ記事（SEO向け・専門性重視）
- SNS投稿（Instagram / X / LinkedIn）
- 会社ニュース・制作実績紹介
- ニュースレター・メルマガ
- クライアント提案書のコンテンツ部分

## 実行手順

1. **テーマと要件をヒアリング**
   - コンテンツの種類（ブログ/SNS等）
   - ターゲット読者（業種・悩み・ニーズ）
   - キーワード（SEO目的の場合）
   - 文字数・投稿プラットフォーム
   - トーン（専門的/親しみやすい/etc.）
   
   ※ 会話の流れで自然に収集できた場合は改めて質問しない

2. **06_learning/ と output/trends/ を参照**
   - 関連する学習メモ・トレンド情報がないか確認
   - あれば内容に盛り込む

3. **MARUDEのブランドトーンに合わせる**
   - **誠実・丁寧**: 押しつけがましくなく、相手の課題を中心に据える
   - **専門性**: Webデザイン・ブランディングの知識を自然に示す
   - **親しみやすさ**: 中小企業・個人事業主が共感できる言葉を使う

4. **下書きを生成**
   - H1タイトル案を3パターン提示
   - 本文下書き（指定フォーマットで）
   - SNSの場合はハッシュタグ案も含める

5. **output/articles/ に保存**
   - ファイル名: `YYYYMMDD_{タイトル略称}.md`
   - 生成日・テーマ・対象プラットフォームをメタ情報として先頭に記載

## ブログ記事の出力テンプレート

```markdown
---
作成日: 
テーマ: 
キーワード: 
対象読者: 
---

# [メインタイトル]

## はじめに
（読者の課題・悩みへの共感から入る）

## [H2セクション1]

## [H2セクション2]

## [H2セクション3]

## まとめ
（要点整理・CTA）
```

## SNS投稿の出力テンプレート

```
【Instagram】
（本文 〜2200文字以内）

#ハッシュタグ #デザイン #webdesign...

---
【X（旧Twitter）】
（140文字以内のバージョン）
```

## 注意事項
- 事実情報（実績・価格・事例）を含める場合は必ずユーザーに確認してから生成
- 競合他社を名指しで批判する内容は生成しない
- 生成した下書きはあくまでも「素材」。最終的な校閲はユーザーが行う
