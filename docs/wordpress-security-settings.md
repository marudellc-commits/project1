# WordPress セキュリティ設定（企業サイト標準）

Wordfence（無料版）+ All-In-One Security（AIOS）構成。機能重複を避けるため役割分担あり。

## 役割分担

| 機能 | 担当 |
|------|------|
| ファイアウォール・スキャン | Wordfence メイン |
| ログイン保護 | Wordfence メイン |
| ファイルシステム保護 | AIOS で補完 |
| ログインURL変更・メタ情報非表示 | AIOS で補完 |
| DBプレフィックス変更 | AIOS（新規サイトのみ推奨） |

**設定順序：Wordfence → AIOS の順番で行う**

---

## Wordfence 設定

### ファイアウォール
- ファイアウォール最適化バナー → 「設定するにはここをクリック」→ サーバー自動検出で実行（事前に .htaccess バックアップ必須）
- 学習モード：1週間後に「有効化された保護」へ自動切り替え（手動で早めない）

### スキャン
- 自動スキャン：毎日自動実行（無料版で動作）
- 問題なければ設定不要

### ログインセキュリティ（Wordfence > ログインセキュリティ > 設定タブ）

| 項目 | 設定 |
|------|------|
| 2FA Roles - Administrator | 必須 |
| Disable XML-RPC authentication | ON |
| reCAPTCHA（Enable reCAPTCHA on login pages） | ON（Googleキー取得後） |

reCAPTCHA キー取得：Google reCAPTCHA サイトで v3 を選択、ドメイン登録して発行

### レート制限（Wordfence > すべてのオプション > レート制限）

| 項目 | 値 | アクション |
|------|-----|--------|
| 誰かのリクエスト数が超過 | 240/分 | スロットル |
| クローラーのページビューが超過 | 120/分 | スロットル |
| クローラーの404が超過 | 30/分 | スロットル |
| 人間のページビューが超過 | 240/分 | スロットル |
| 人間の404sが超過 | 30/分 | スロットル |
| IPブロック期間 | 1時間 | - |

※ 404はブロックではなくスロットルに設定（false positive 防止）

## AIOS 設定

### ユーザーアカウント
- `admin` ユーザー名を使わない

### ブルートフォース
- ログインURL変更 → ON
- **ログインロックアウト → OFF**（Wordfenceが担当するため競合を避ける）

### ファイルシステムセキュリティ
- wp-config.php のアクセス権を 440 に変更 → ON
- .htaccess / .htpasswd へのアクセス防止 → ON
- PHPファイルの編集を無効化 → ON

### ファイアウォール
- 基本的なファイアウォールルール → ON
- WPジェネレータのメタ情報を削除 → ON

### データベースセキュリティ
- DBプレフィックス変更：**既存サイトはスキップ推奨**（リスク大）
- 新規サイトなら実施（必ずバックアップ後）

---

## 設定引き継ぎ方法（新サイトへの展開）

Wordfence の設定は以下でエクスポート・インポート可能：
> Wordfence > すべてのオプション > オプションのインポート / エクスポート

AIOS は手動で上記チェックリストに沿って設定する。
